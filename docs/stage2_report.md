## 3. 驗收清單（16/16）與「通過」的意義

所有項目由驗收腳本從資料庫實際計算，不是手寫。需要特別說明的三項：

- **「能執行 OHLC／重複／前視偏誤檢查」通過**＝檢查程式可運作並有測試；不代表資料完美。目前資料品質結果見 §4。
- **「能產生倖存者偏誤限制報告」通過**＝報告已產生；**報告的結論是「不能宣稱已消除倖存者偏誤」**。
- **「能取得可用的下市股票資料」通過**＝FinMind 下市股有日線（3068、6022、1333 驗證）；下市清單本身仍不完整（§5）。

## 5. 資料覆蓋與倖存者偏誤

- 股票池：3,632 檔證券；2013 年後存在過的普通股 2,163 檔（含下市）。
- 櫃買中心 167 份月快照中出現的上櫃普通股 1,021 檔，**全部在股票池中**；其中漢磊 5326 不在 FinMind 任何清單，是在第一次下載時由下載器自動補入並標記。
- 下市股市場別：41 檔判定為上櫃；**431 檔仍未知**（多為上市股，因證交所網站無法連線而無法確認）。
- **限制**：上市（TWSE）股票未經官方比對；每月只比對一天，月中上市又下市者可能遺漏。**不能宣稱已消除倖存者偏誤。**
