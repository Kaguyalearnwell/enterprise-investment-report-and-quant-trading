## 第三部分：策略經濟直覺與 Alpha 假設

### 3.1 六個問題

**1. 試圖捕捉什麼市場行為？**
「**波動率狀態轉換 + 趨勢延續**」：在已有中期上升趨勢的股票上，價格經過一段低波動整理（籌碼沉澱、多空暫時平衡）後，以放量方式脫離整理區間，代表新資訊或新資金進入，價格傾向沿原趨勢延續一段時間。本質上是**時間序列動能（time-series momentum）**與**波動率群聚（volatility clustering）**的組合。

**2. 為什麼均線多頭排列可能有預測力？**
- 行為面：投資人對新資訊**反應不足**（under-reaction）、錨定效應，使價格逐步而非一次反映資訊，形成趨勢。
- 結構面：法人分批建倉、台股投信作帳、外資持續買超，使需求在時間上自我相關。
- 文獻：時間序列動能（Moskowitz, Ooi & Pedersen 2012）、截面動能（Jegadeesh & Titman 1993）在多數市場存在，但台股截面動能證據**較弱且不穩定**，這是必須以數據驗證而非預設的原因。
- **限制**：MA 排列是落後指標，13/34/55 的平均延遲約 6/17/27 日；它過濾的是「已發生的趨勢」，預測力取決於趨勢延續的機率，而非排列本身。

**3. 為什麼低波動壓縮後可能出現趨勢性突破？**
- 波動率具有**均值回歸**：極低波動不會永遠持續，之後波動擴張的機率高（這部分統計上相對可靠）。
- 但**波動擴張不等於上漲**：壓縮只預測「會動」，不預測「方向」。方向必須由 M1/M3/M4 提供 → 這正是要驗證 M1 × M2 **交互作用**的原因。
- 整理期間形成明確的支撐/壓力，突破時停損價位清楚，有利於風險控管（R 倍數較好計算），這是一個**執行面**而非預測面的優勢。

**4. 為什麼跨週期確認可能改善訊號品質？**
日線突破有大量雜訊；週線趨勢代表較長期資金方向。理論上可降低「逆大勢突破」的假訊號比例。代價是延遲：週線濾網在空頭轉多頭初期會擋掉早期突破。**預期效果是降低 MDD，不一定提高報酬**（即 H3）。

**5. 最可能獲利的環境**：中期多頭、個股輪動明顯、波動率正常偏低後擴張（例：2016–2017、2019、2023–2024 的台股）。

**6. 最可能虧損的環境**：
- 高波動區間震盪（突破後迅速回落，假突破連續停損）。
- 空頭初期（MA 尚未翻空，仍給出多頭訊號）。
- 快速 V 轉（MA 排列落後，進場時已漲一大段）。
- 系統性跳空（如 2020-03、2024-08-05 單日重挫），停損被跳空穿越。

### 3.2 可否證假設

以下假設皆以**扣除一般成本情境後**的報酬檢驗，主要預測期間 h ∈ {5, 10, 20} 交易日。

| 假設 | 內容 | H0（虛無假設） | 檢定方法 |
|---|---|---|---|
| **H1** | MA 多頭排列下的壓縮突破，未來報酬優於非排列下的壓縮突破 | `E[r | BO, MA=1] − E[r | BO, MA=0] ≤ 0` | 迴歸 `r = α + β·MA + γ_date + ε`，日期固定效果，日期叢集 SE；單尾 |
| **H2** | 低 BW 百分位後的向上突破，延續機率高於非壓縮下的突破 | `P(延續 | BO, SQ=1) ≤ P(延續 | BO, SQ=0)` | 延續定義：`C_{t+h} > C_t` 且期間最低價未跌破 `C_t − 1·ATR_t`；Logit + 日期叢集 SE |
| **H3** | 加入週線濾網後 MDD 下降，但 CAGR 不一定上升 | `MDD_E ≥ MDD_D` | Stationary block bootstrap（Politis–Romano）配對差異，2,000 次 |
| **H4**（交互作用，**核心**） | MA 與 BB 結合有超過兩者相加的額外 Alpha | `β_{MA×SQBO} ≤ 0` | 2×2 因子迴歸 `r = α + β₁·MA + β₂·SQBO + β₃·MA·SQBO + γ_date + ε` |
| **H5** | 成交量確認提高突破品質 | `E[r | BO, VOL=1] ≤ E[r | BO, VOL=0]` | 同 H1 架構 |
| **H6** | 策略優勢扣除壓力成本後仍存在 | 壓力成本下 `Expectancy ≤ 0` | 交易層級報酬之 bootstrap 信賴區間下界 > 0 |

### 3.3 統計檢定的共同規範

1. **報酬起點**：一律從**可成交價格** `O_{t+1}` 起算：`r_{t,h} = C_{t+h} / O_{t+1} − 1`，而非從訊號日收盤價起算（後者會把隔夜跳空算成策略績效）。
2. **超額報酬**：同時報告原始報酬與相對大盤（加權報酬指數）報酬，以排除「只是大盤漲」。
3. **事件相依性**：同一天多檔突破高度相關。採兩種方法並列：
   - 事件層級：**日期叢集穩健標準誤**（cluster by date）。
   - 投組層級：**日曆時間投組法**：每日把所有在持有期內的事件等權組合，得到一條日報酬序列，再用 **Newey–West** t 檢定（lag = h）。
4. **重疊報酬**：h 日報酬在相鄰日重疊，必須使用 Newey–West 或非重疊抽樣。
5. **多重檢定**：H1–H6 為事前登記的主要假設，用 **Holm–Bonferroni** 控制家族錯誤率；參數搜尋另以 DSR/PBO 處理（§8.5）。

## 第四部分：數學公式與訊號定義

### 4.0 符號與時序約定

- `O_t, H_t, L_t, C_t, V_t`：第 t 個交易日的開高低收量（**訊號計算用還原價**；量依股本變動調整）。
- `Ô_t, Ĥ_t, L̂_t, Ĉ_t`：原始（未還原）價格，**只用於撮合、漲跌停與檔位**。
- **可用時間原則**：任何以 `t` 為下標的指標，只使用 `≤ t` 的收盤後資訊，於 **t 日收盤後** 可得；據此產生的委託最早於 **t+1 開盤** 執行。
- 程式層面：訊號欄位 `signal_t` 計算後，成交欄位使用 `signal.shift(1)` 對齊到成交日。

### 4.1 移動平均

```
MA_n(t) = (1/n) · Σ_{i=0}^{n-1} C_{t-i},    n ∈ {13, 34, 55}
```

有效起點：t ≥ 55（前 54 日為 NaN，不產生訊號）。

### 4.2 均線斜率（標準化）

```
Slope_n(t) = (MA_n(t) − MA_n(t−k)) / (k · ATR_14(t))      預設 k = 5
```

用 ATR 標準化，使不同價位、不同波動的股票可比較。替代定義（敏感度測試用）：`(MA_n(t)/MA_n(t−k) − 1)/k`。

### 4.3 均線間距與糾結度

```
Spread(t)  = (MA_13(t) − MA_55(t)) / ATR_14(t)                 # 趨勢強度
Tangle(t)  = (max(MA_13, MA_34, MA_55) − min(·)) / C_t         # 糾結度，越小越糾結
AlignAge(t)= 連續滿足 Bull(t) 的天數                             # 排列持續時間
```

ATR（Wilder）：

```
TR_t   = max(H_t − L_t, |H_t − C_{t−1}|, |L_t − C_{t−1}|)
ATR_14(t) = ATR_14(t−1) + (TR_t − ATR_14(t−1)) / 14
```

### 4.4 Bollinger Bands

```
M_t = MA_20(t)
σ_t = sqrt( (1/20) · Σ_{i=0}^{19} (C_{t−i} − M_t)² )      # 母體標準差，ddof = 0
U_t = M_t + k·σ_t,    L_t^BB = M_t − k·σ_t,    k = 2
```

> ⚠️ pandas `Series.rolling(20).std()` 預設 `ddof=1`，需明確寫 `.std(ddof=0)`。

### 4.5 Bandwidth

```
BW_t = (U_t − L_t^BB) / M_t = 2k·σ_t / M_t
```

### 4.6 Bandwidth 滾動百分位

```
BWP_t = (1/W) · Σ_{i=0}^{W−1} 1[ BW_{t−i} ≤ BW_t ]       W = 252（約一年）
```

- 視窗**只含 t 及以前**（尾端對齊），包含當日 BW_t 是允許的，因為它在 t 日收盤已知。
- 有效起點：t ≥ 20 + 252 − 1 ≈ 271 個交易日。新上市股票前約 13 個月不產生訊號。
- ❌ 禁止：`BW.rank(pct=True)`（全樣本），或以全期間分位數做門檻。

### 4.7 壓縮狀態與釋放

```
SQ_t        = 1[ BWP_t ≤ q ]                                q 預設 0.20
SQLen_t     = 連續滿足 SQ 的天數
SQRelease_t = 1[ Σ_{i=1}^{m} SQ_{t−i} ≥ 1 ] · 1[ BW_t > BW_{t−1} ]     m 預設 5
```

`SQRelease` 意為「最近 m 日內曾處於壓縮，且今日帶寬開始擴張」。可加最小壓縮長度：`max_{i∈[1,m]} SQLen_{t−i} ≥ L_min`（預設 L_min = 5）。

整理區間（用於停損與目標）：

```
BoxHigh_t = max(H_{τ..t−1}),  BoxLow_t = min(L_{τ..t−1})，τ = 最近一段壓縮的起始日
```

### 4.8 突破訊號（候選，消融時逐一測試）

```
BO_BB_t   = 1[ C_t > U_t ]
BO_N_t    = 1[ C_t > max(H_{t−N}, …, H_{t−1}) ]       N 預設 20，**排除當日**
BO_Box_t  = 1[ C_t > BoxHigh_t ]
```

成交量確認：

```
VOL_t = 1[ V_t > κ · MA_20(V)(t−1) ]                    κ 預設 1.5
```

> 量能均值用 `t−1` 為止，避免當日巨量拉高自身基準。

### 4.9 多週期濾網（週線）

週 K 定義：第 w 週的 OHLCV 由該週所有交易日聚合，**時間戳 = 該週實際最後一個交易日**（不是週五、不是週一）。

```
MTF_w = 1[ MA13^W_w > MA34^W_w > MA55^W_w ] · 1[ Slope^W_55(w) > 0 ] · 1[ C^W_w > MA55^W_w ]
```

對齊到日線：

```
MTF_t^D = MTF_{w*},    w* = max{ w : LastTradingDay(w) ≤ t }
```

- 在週最後交易日 t 收盤時，該週 K 已完成，日線訊號同樣在 t 收盤產生，故 `≤ t` 合法。
- 保守版（敏感度測試）：`< t`，即只用上一個已完成的週 K。
- 實作：`pd.merge_asof(daily, weekly, left_on="date", right_on="week_end_date", direction="backward")`。
- ❌ 禁止：`resample("W").last().reindex(daily_index, method="bfill")`，或以 `W-MON` 週起始標籤對齊 — 會把週五才知道的收盤價提前到週一使用。
- 注意：週線 MA55 ≈ 一年以上資料，有效起點約 55 週。

**60 分鐘線（延伸研究）**：K 棒時間戳 = **結束時間**；訊號於 K 棒結束時產生、下一根 K 棒開盤成交；日線/週線濾網只能使用前一個已收盤交易日的值（盤中當日日 K 尚未完成）。

### 4.10 Regime 與 Liquidity Filter

**Regime（趨勢狀態，M1）**：

```
Bull_t  = 1[ MA13_t > MA34_t > MA55_t ]
Bear_t  = 1[ MA13_t < MA34_t < MA55_t ]
Trend_t = Bull_t · 1[ Slope_55(t) > 0 ] · 1[ C_t > MA34_t ]
```

（市場層級 Regime 作為**分析切片**，不作交易條件：加權指數 `C > MA200` 為多頭市況。）

**Liquidity（必要條件，不參與消融）**：

```
Liq_t = 1[ median_{i=1..20}(Ĉ_{t−i} · V̂_{t−i}) ≥ NT$ 50,000,000 ]
      · 1[ Ĉ_t ≥ 10 ]
      · 1[ 非全額交割股、非處置股、非停止交易 ]
      · 1[ 上市櫃滿 271 個交易日 ]
```

並限制單筆部位 ≤ 該股 20 日平均成交值的 5%（容量限制）。

### 4.11 完整布林邏輯

**Entry Long（完整版 = Strategy E）**，於 t 收盤判定、t+1 開盤執行：

```
EntryLong_t = Liq_t ∧ Flat_t ∧ Trend_t ∧ SQRelease_t ∧ BO_t ∧ VOL_t ∧ MTF_t^D
```

其中 `BO_t` 為 §4.8 擇一（由消融決定），`Flat_t` = 目前無該檔部位。

**Exit Long**（任一成立；停損為盤中觸價，其餘為收盤判定 t+1 開盤執行）：

```
(1) 初始停損：  L̂_s ≤ Stop₀                                  盤中觸發
                Stop₀ = max(Entry − 2·ATR_14(t), BoxLow_t)     （t = 訊號日，進場前已知）
(2) 追蹤停損：  C_s < max_{j∈[entry, s]} H_j − 3·ATR_14(s)      收盤判定
(3) 趨勢失效：  C_s < MA_34(s)                                收盤判定（預設；MA13/中軌為替代）
(4) 時間停損：  持有 ≥ T_max = 60 日 且 未實現報酬 < 1R          收盤判定
```

> 出場規則在消融 A–E 中**固定不變**；出場方式本身另於 §6.2 獨立比較。

**Entry/Exit Short**：預設停用。若 Stage 2 啟用，邏輯對稱（Bear、`C_t < L_t^BB`、`C_t < min(L_{t−N..t−1})`），並需額外模擬：融券券源、平盤下限制、股東會及除權息前停券與強制回補、借券費。

## 第五部分：模組化與消融實驗設計

### 5.1 為什麼原本的 A→E 不夠

原設計是單一路徑的巢狀階梯，只能回答「**在已有 MA 濾網的前提下**，再加 BB 有沒有幫助」，無法回答「**BB 突破本身**有沒有 Alpha」或「兩者是否互補」。因此擴充為兩組實驗：

### 5.2 實驗一：2×2 因子設計（回答核心問題）

所有格子使用**相同的出場規則、相同的倉位管理、相同的成本**。

| | 無壓縮突破條件 | 有壓縮突破（SQRelease ∧ BO） |
|---|---|---|
| **無 MA 濾網** | **S_rand**：隨機進場（配對持有期分布，500 次模擬） | **S0**：純 BB 壓縮突破 |
| **有 MA 濾網** | **A**：MA 排列成立首日進場（`Bull_t ∧ ¬Bull_{t−1}`，或排列中每次 `C` 站回 MA13） | **C**：MA + 壓縮 + 突破 |

- **MA 主效果** = (A − S_rand) 與 (C − S0) 的平均
- **BB 主效果** = (S0 − S_rand) 與 (C − A) 的平均
- **交互作用（額外 Alpha）** = (C − A) − (S0 − S_rand)
  - 若交互作用 ≈ 0：兩者只是加總，沒有協同效應，可考慮更簡單的單一模組。
  - 若 > 0 且樣本外仍顯著：這才是「結合產生的額外 Alpha」。

事件層級等價迴歸（H4）：

```
r_{i,t,h} = α + β₁·MA_{i,t} + β₂·SQBO_{i,t} + β₃·MA_{i,t}·SQBO_{i,t} + γ_t + ε_{i,t}
```

以「所有通過流動性濾網的股票日」為母體，`γ_t` 為日期固定效果（吸收大盤當日影響），日期叢集 SE。

### 5.3 實驗二：巢狀階梯（回答每個濾網的邊際貢獻）

| 版本 | 條件 | 新增模組 |
|---|---|---|
| A | `Trend` 進入事件 | — |
| B | `Trend ∧ SQRelease`（無突破，壓縮釋放當日進場） | 壓縮 |
| C | `Trend ∧ SQRelease ∧ BO` | 價格突破 |
| D | C ∧ `VOL` | 成交量 |
| E | D ∧ `MTF` | 多週期 |
| **另增：留一法（Leave-one-out）** | E 分別拿掉 MA / SQ / BO / VOL / MTF | 測每個模組在**完整策略中**的必要性 |

留一法很重要：濾網的邊際價值與加入順序有關（VOL 在 C 之後加入有用，不代表在 E 中仍必要）。

### 5.4 訊號重複度分析

對每對條件 X, Y（在流動性母體的股票日上）：

```
Jaccard(X, Y)     = |X ∧ Y| / |X ∨ Y|
Lift(Y | X)       = P(Y | X) / P(Y)
Redundancy(Y | X) = P(Y | X)       # 若 ≈ 1，則在已有 X 時 Y 幾乎不過濾任何東西
```

先驗預期高度重複的組合：
- `BO_BB`（C > 上軌）與「C > MA13 且 C > MA34」：在 MA 多頭排列時，上軌通常高於 MA13/MA34，條件幾乎恆成立 → **建議刪除「價格在 MA13/MA34 上方」作為獨立條件**，除非數據顯示其 Redundancy < 0.9。
- `SQRelease` 與 `BO_BB`：帶寬擴張常由突破上軌造成（同一個價格變動），兩者可能是同一事件的兩種描述。
- `BO_BB` 與 `BO_N`：在低波動壓縮後，上軌與 20 日高點接近。

### 5.5 刪除濾網的決策規則（事前登記）

一個模組**保留**的條件為以下皆成立：
1. 在 Validation 期，加入後 Sharpe 提升，且配對 block bootstrap 差異的 90% 信賴區間下界 > 0；
2. 或 Sharpe 持平（差異 CI 含 0）但 **MDD 改善 ≥ 20%** 且 CAGR 下降 < 15%；
3. 交易次數不得降至 OOS 期 < 30 筆/年（統計檢定力底線）。

否則刪除。**此規則在看 OOS 結果前固定，不得事後修改。**

### 5.6 比較指標

CAGR、Sharpe、Sortino、MDD、Win Rate、Profit Factor、平均持有天數、交易次數、年化換手率、單筆期望報酬（以 R 倍數及 % 兩種表示），以及**相對隨機進場的超額期望值**。

## 第六部分：進出場與資金管理

### 6.1 三種進場方法（訊號日 = t）

| 方法 | 委託 | 成交模型（原始價） | 有效期 |
|---|---|---|---|
| **A. 次日開盤** | t 收盤後下 t+1 市價單 | `fill = Ô_{t+1} × (1 + slip)`；若 `Ô_{t+1} ≥ LimitUp_{t+1}` 且 `Ĥ = L̂`（一價到底）→ **不成交** | 1 日 |
| **B. 回測進場** | 限價單，價位 `P = max(U_{s−1}, MA13_{s−1})`（前一日已知） | 若 `L̂_s ≤ P`：`fill = min(Ô_s, P)` | s ∈ [t+1, t+5]；期間若收盤跌破 `BoxHigh_t` 視為突破失敗，取消 |
| **C. ATR 追蹤進場** | 停損買單，價位 `P = Ĥ_t + 0.25·ATR_t` | 若 `Ĥ_s ≥ P`：`fill = max(Ô_s, P) × (1 + slip)` | s ∈ [t+1, t+5] |

比較：勝率、平均獲利、平均虧損、MDD、交易頻率、風險報酬比，**以及錯過率**（B 方法常錯過最強的突破，這是其主要成本——強勢股往往不回測）。

### 6.2 出場方式（獨立實驗，進場固定為 Strategy C/D + 方法 A）

| 出場 | 定義 | 預期特性 |
|---|---|---|
| MA13 跌破 | `C_s < MA13_s` | 快、勝率低、易被洗出 |
| MA34 跌破 | `C_s < MA34_s` | 中速（預設） |
| 中軌跌破 | `C_s < M_s`（MA20） | 介於兩者之間 |
| ATR Trailing | `C_s < HH_s − m·ATR_s`，m ∈ {2, 3, 4} | 參數敏感 |
| 固定 R:R | 目標 `Entry + R_mult·(Entry − Stop₀)`，R_mult ∈ {2, 3} | 截斷右尾，與趨勢策略本質衝突 |
| Time Stop | 持有 T 日未達 1R 出場 | 提升資金周轉 |

所有出場都**疊加初始停損 Stop₀**。

### 6.3 停損的跳空處理

```
若 Ô_s ≤ Stop：         fill = Ô_s × (1 − slip)          # 跳空穿越，以開盤價出場（虧損 > 1R）
否則若 L̂_s ≤ Stop：     fill = Stop × (1 − slip)
若當日跌停鎖死（Ĥ_s = L̂_s = LimitDown_s）：不成交，延至下一個可成交日開盤
```

每筆交易紀錄**實現 R 倍數**；回報 R 分布中 < −1.5R 的比例（跳空風險指標）。

### 6.4 倉位計算

```
R_$      = Equity_t × risk_pct × DD_scale_t                  # risk_pct = 1%
StopDist = max(Ĉ_t − Stop₀, 0.5·ATR̂_t)                       # 以 t 收盤估算，下限防止極窄停損放大部位
Shares_raw = R_$ / StopDist
Shares   = min( Shares_raw,
                0.15·Equity_t / Ĉ_t,                         # 單一標的上限
                0.05·ADV20_value_t / Ĉ_t,                     # 容量限制
                可用現金 / (Ĉ_t·(1+fee+slip)) )
Shares   = floor 到交易單位（整股 1,000 股；或允許零股時 1 股，見 §7.3）
```

- **以 `Ĉ_t` 而非 `Ô_{t+1}` 計算股數**，因下單時尚不知開盤價；成交後以實際 fill 重算實際風險並紀錄差異。
- ATR 波動率調整已內含於 StopDist（停損 = 2·ATR），高波動股自動降低部位。
- 產業集中度：加入新部位後若某產業曝險 > 35%，按比例縮減或放棄該訊號。
- 同日訊號數超過可用資金時的排序規則（事前固定）：依 `Spread_t` 由高至低；並以隨機排序做敏感度測試（若排序影響巨大，代表結果脆弱）。

### 6.5 回撤減倉機制

```
DD_t = 1 − Equity_t / max_{j≤t} Equity_j
DD_scale_t = 1.0   若 DD_t < 10%
             0.5   若 10% ≤ DD_t < 20%
             0.25  若 DD_t ≥ 20%
恢復：DD_t 回到 < 5% 才回升至 1.0（遲滯設計，避免頻繁切換）
```

此機制本身也需做「有/無」比較：它在 V 型反轉中會降低回復速度。

### 7.1 成本參數

| 項目 | 規定 | 樂觀 | 一般 | 壓力 |
|---|---|---|---|---|
| 手續費（買、賣各一次） | 法定上限 0.1425% | 0.1425% × 2.8 折 ≈ 0.040% | 0.1425% × 6 折 ≈ 0.0855% | 0.1425%（無折扣） |
| 手續費最低收費 | 依券商，常見整股 NT$20 | 同左 | 同左 | 同左 |
| 證券交易稅（賣出） | 普通股 0.3% | 0.3% | 0.3% | 0.3% |
| 滑價（單邊） | — | 0.05% | 0.15% | 0.30%，或依參與率 `0.1% + 10%·√(order/ADV)` |

補充：

- 往返成本約 0.5–1.2%，對平均持有 10–30 日的突破策略是**決定性變數**：若單筆期望報酬 < 1.5%，壓力情境下很可能轉負。

### 7.2 漲跌停與檔位

- 漲跌幅限制：前一日收盤價（參考價）±10%，依檔位規則取整。
- 升降單位（tick）：

| 股價 | < 10 | 10–50 | 50–100 | 100–500 | 500–1,000 | ≥ 1,000 |
|---|---|---|---|---|---|---|
| Tick | 0.01 | 0.05 | 0.1 | 0.5 | 1 | 5 |

- 成交價須取整到 tick（買進向上、賣出向下取整）。
- **漲停買不到**：`Ô ≥ LimitUp` 時視為無法以市價買進；若 `Ĥ = L̂ = LimitUp` 一律不成交。保守設定：開盤即漲停者一律不成交。
- **跌停賣不出**：`Ĥ = L̂ = LimitDown` 時不成交，部位遞延，並紀錄「被鎖死天數」。

### 7.3 交易單位

- 整股 1 張 = 1,000 股；盤中零股自 2020-10 起可交易，但流動性較差、滑價應加倍。
- 以 NT$300 萬、單筆風險 1%（NT$3 萬）、停損距離 2·ATR 估算，高價股（如千元以上）整股常無法買足 → 研究預設**允許零股**，並另跑「僅整股」版本檢視差異。

### 7.4 還原價與原始價分離

- 指標與訊號：使用**還原權值價**（含現金股利再投入），避免除息缺口觸發假停損/假跌破。
- 撮合、漲跌停、tick、股數、手續費與稅：使用**原始價**。
- 持有期間發生除權息：現金股利入帳（需考慮二代健保補充保費與股利所得稅屬投資人層級，研究預設忽略但需揭露），配股增加持股。

## 第八部分：回測與統計驗證架構

### 8.1 資料與偏誤處理

| 偏誤 | 處理 |
|---|---|
| Survivorship | 母體需包含**已下市**股票。yfinance 台股不含下市股 → 只能作為原型；正式研究建議 TEJ、或含下市資料之付費來源。若僅能用 yfinance，報告必須標示「存活者偏誤：績效可能高估」 |
| Look-ahead | §4 所有指標尾端對齊；自動化測試：把 t 之後的資料改成亂數，t 以前的訊號必須完全不變（**未來資料擾動測試**） |
| 時點正確的母體 | 每日母體為「當日已上市且通過流動性濾網」者，不得用今日的成分股回推過去 |
| Corporate actions | 還原價 + 原始價雙軌；減資、合併、下市最後交易日強制以最後成交價出場 |
| Missing data | 停牌日不交易、不前向填補價格產生假訊號；指標遇缺值時該視窗無效 |
| Delisted | 下市前最後價出場；下市後價值歸零的情況（如全額交割後下市）需納入 |
| Data snooping | 見 §8.5 |

### 8.2 資料切分

```
|——— In-Sample 50% ———|gap|— Validation 25% —|gap|— Out-of-Sample 25% —|
```

- 依**時間**切分，不隨機抽樣。
- 各段之間設 **embargo gap = 60 交易日**（≥ 最長持有期），避免持倉跨段造成資訊滲漏。
- 指標可用全歷史因果計算（不會洩漏），但**績效只計算該段內開倉的交易**。
- OOS 段**只看一次**。看過後若修改策略，該 OOS 即降級為 Validation，需新的 OOS（例如等待未來資料、或改用其他市場如美股作為外部驗證）。

### 8.3 Walk-Forward

- **Rolling**：訓練 4 年 → 測試 1 年 → 每年滾動。
- **Expanding**：訓練從起點累積 → 測試 1 年。
- 每個訓練窗只在**有限網格**內挑選參數，且挑選規則為「**參數高原中心**」而非單點最佳（§8.4）。
- 拼接所有測試窗得到 WFA 淨值曲線，報告 **WFA Efficiency = OOS 年化報酬 / IS 年化報酬**（> 0.5 為可接受參考值）。

### 8.4 參數高原測試

有限網格（事前固定）：

| 參數 | 範圍 | 個數 |
|---|---|---|
| MA 組 | (8,21,34), (13,34,55), (21,55,89) | 3 |
| BB Period | 15, 20, 25, 30 | 4 |
| BB Std k | 1.5, 2.0, 2.5 | 3 |
| BW 百分位 q | 0.05, 0.10, 0.20, 0.30 | 4 |
| 突破期間 N | 10, 20, 30 | 3 |

共 432 組（每個策略版本）。報告：

1. 最佳參數與次佳參數。
2. 每對參數的 Sharpe 熱力圖。
3. **鄰域平均 Sharpe**：每組參數與其網格相鄰組的平均；選鄰域平均最高者為「穩健參數」。
4. 穩健度 = 鄰域 Sharpe 標準差；若最佳點周圍急劇下降 → 判定為過度擬合尖峰。
5. 參數在牛市/熊市/盤整市況下的排名相關性（Spearman），檢查參數是否穩定。

### 8.5 多重檢定與過擬合控制

- **試驗登記簿**：紀錄每一次回測（版本 × 參數 × 進出場 × 成本），總試驗數 N_trials 寫入報告。
- **Deflated Sharpe Ratio**（Bailey & López de Prado 2014）：考慮 N_trials、報酬偏態與峰態，回報 `DSR = P(SR_true > 0)`；參考門檻 DSR > 0.95。
- **PBO（Probability of Backtest Overfitting）**：以 CSCV（Combinatorially Symmetric Cross-Validation，S = 16 區塊）估計；PBO > 0.5 表示最佳參數在樣本外表現低於中位數的機率過半 → 判定過擬合。
- **White's Reality Check / Hansen SPA**：檢驗「最佳策略是否顯著優於基準」，控制整個網格的資料探勘。

### 8.6 Bootstrap 與 Monte Carlo

| 方法 | 目的 |
|---|---|
| Stationary block bootstrap（日報酬，平均區塊長度 20） | Sharpe、CAGR、MDD 的信賴區間；策略間配對差異檢定 |
| 交易序列重排（Trade reshuffling，10,000 次） | MDD 與最長連續虧損的分布（評估路徑風險） |
| 交易層級 bootstrap | Expectancy 與 Profit Factor 信賴區間 |
| 隨機進場基準（500 次） | 配對相同持有期分布與相同出場規則，建立「無技能」績效分布；策略應位於 > 95 百分位 |
| 參數擾動（每個參數 ±10–20% 隨機擾動） | 測試結果對參數微調的敏感度 |

## 第九部分：績效評估與及格門檻

### 9.1 指標定義（日報酬 r_t，年化因子 252）

```
CAGR          = (Equity_T / Equity_0)^(252/T) − 1
Vol           = std(r_t) · √252
Sharpe        = (mean(r_t − rf_t) / std(r_t)) · √252          rf = 台灣一年期定存利率（日化）
Sortino       = (mean(r_t − rf_t) / DD_σ) · √252,  DD_σ = sqrt(mean(min(r_t − rf_t, 0)²))
MDD           = max_t (1 − Equity_t / max_{j≤t} Equity_j)
MDD Duration  = 最長「低於前高」的連續交易日數
Calmar        = CAGR / MDD
Win Rate      = #(trade_pnl > 0) / #trades
Payoff Ratio  = mean(win) / |mean(loss)|
Profit Factor = Σ win / |Σ loss|
Expectancy    = WinRate·mean(win) − (1−WinRate)·|mean(loss)|  （以 % 與 R 倍數各報一次）
Turnover      = Σ |交易金額| / mean(Equity) / 年數
Exposure      = 有持倉的平均資金比例
```

### 9.2 基準

| 基準 | 用途 |
|---|---|
| 0050 Buy & Hold（含息） | 被動投資替代方案 |
| 加權股價**報酬**指數 | 大盤（必須用報酬指數，因台股股利率高，價格指數會低估大盤約 3–4%/年） |

| **曝險配對基準**：`Exposure × 大盤 + (1 − Exposure) × 現金` | 策略平均只投入部分資金時的公平比較 |
